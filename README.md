# 💰 EconoQuiz: Gamificando a Educação Financeira

<div align="center"><img src="./assets/Logo_EconoQuiz.png" alt="Logo EconoQuiz" width="150"></div>

O **EconoQuiz** é uma plataforma de quiz gamificada desenvolvida para
educar e engajar usuários em **Educação Financeira** e **Cidadania
Econômica**. Nosso objetivo é transformar temas complexos --- como
orçamento, investimentos e serviços financeiros --- em uma experiência
competitiva e acessível.

---

## ✨ Objetivo do Jogo e Funcionalidades

O **EconoQuiz** é um sistema robusto e ágil, com foco no engajamento
contínuo na literacia financeira.

---

## 🎮 Mecânica de Jogo

- **Partidas Dinâmicas**: Os usuários jogam partidas com questões de
  dificuldade variada (Fácil, Médio, Difícil).
- **Progressão**: A cada acerto, o usuário acumula pontos que definem
  seu nível de jogo.
- **Competição**: O usuário acompanha sua posição no ranking geral,
  que é atualizado em tempo real.

---

## 🛡️ Qualidade e Tecnologia

O sistema é construído sobre pilares de performance e segurança:

- **Segurança**: Garante segurança nos fluxos de cadastro e login
  (dados criptografados).
- **Performance**: Carregamento rápido de conteúdo e interface
  responsiva (mobile e desktop).
- **Disponibilidade**: Projetado para ser uma ferramenta robusta e
  ágil para engajamento contínuo.

---

## 📊 Justificativa

A **Educação Financeira** é um pré-requisito crucial para que os
cidadãos acessem e utilizem serviços financeiros de forma consciente.\
Ao elevar a literacia financeira de forma gamificada, o EconoQuiz
capacita os usuários a gerir melhor seus recursos, contribuindo para a
construção de um sistema mais inclusivo e apoiando o crescimento
econômico sustentável.

## ⚙️ Configuração e Instalação

O projeto está dividido em duas partes: **frontend** e **backend**.

### 🔹 1. Clone o Repositório

```bash
git clone [LINK_DO_SEU_REPOSITORIO]
cd econoquiz
```

### 🔹 2. Configuração do Backend

```bash
cd backend
npm install # ou yarn install
```

- Crie um arquivo `.env` com as credenciais do seu banco.
- Execute as migrações:

```bash
npm run migrate
```

- Inicie o servidor:

```bash
npm run dev # ou yarn run dev
```

### 🔹 3. Configuração do Frontend

```bash
cd ../frontend
npm install # ou yarn install
```

- Configure as variáveis de ambiente (ex: URL da API do backend).
- Inicie o servidor de desenvolvimento:

```bash
npm run dev # ou yarn run dev
```

O **frontend** estará disponível normalmente em `http://localhost:5173`
(ou porta configurada)\
e o **backend** em `http://localhost:3000` (ou porta configurada).
